# Domain Model — Warehouse Management

## Scope (v1)
Μία αποθήκη, με θέσεις αποθήκευσης, υλικά και κινήσεις αποθέματος.

## Actors
| Actor | Ρόλος |
|---|---|
| Αποθηκάριος (Storekeeper) | Καταχωρεί παραλαβές, χορηγήσεις, μεταφορές μεταξύ θέσεων |
| Υπεύθυνος Αποθήκης (Warehouse Manager) | Εγκρίνει διορθώσεις, κλείνει απογραφές, διαχειρίζεται υλικά και θέσεις |
| Επιτροπή Παραλαβής (Receiving Committee) | Πιστοποιεί ότι η παραλαβή είναι σύμφωνη με τις προδιαγραφές |
| Τμήμα Πωλήσεων (Sales) | Εγκρίνει τα αιτήματα χορήγησης. Δεν κάνει κινήσεις αποθέματος |
| Ελεγκτής (Auditor) | Μόνο ανάγνωση: ιστορικό κινήσεων και αναφορές |

## Ubiquitous Language
| Όρος | Ορισμός |
|---|---|
| **Item** | Υλικό που διαχειρίζεται η αποθήκη. Ταυτοποιείται μοναδικά από τον κωδικό του (SKU). |
| **SKU** | Μοναδικός κωδικός υλικού. Δεν αλλάζει μετά τη δημιουργία. |
| **Unit of Measure** | Μονάδα μέτρησης του υλικού (τεμάχιο, κιβώτιο, λίτρο, κιλό). |
| **Location** | Συγκεκριμένη θέση αποθήκευσης (π.χ. διάδρομος-ράφι-επίπεδο: A-03-2). |
| **Batch / Lot** | Παρτίδα υλικού με κοινή ημερομηνία παραλαβής και, αν ισχύει, ημερομηνία λήξης. |
| **Stock Level** | Η ποσότητα ενός υλικού σε μια θέση (και παρτίδα) σε μια χρονική στιγμή. Υπολογίζεται από τις κινήσεις. |
| **Stock Movement** | Αμετάβλητη καταγραφή μιας μεταβολής αποθέματος, με τύπο, ποσότητα, ημερομηνία, χρήστη και αιτιολογία. |
| **Goods Receipt** | Είσοδος υλικού στην αποθήκη (παραλαβή). |
| **Expected Quantity** | Η ποσότητα που αναμένεται σε μια παραλαβή, σύμφωνα με το παραστατικό του προμηθευτή. |
| **Outstanding Quantity** | Η ποσότητα που υπολείπεται μετά από ελλειμματική παραλαβή και αναμένεται να συμπληρωθεί. |
| **Issue Request** | Αίτημα χορήγησης υλικού. Πρέπει να εγκριθεί από το Τμήμα Πωλήσεων πριν εκτελεστεί. |
| **Issue** | Έξοδος υλικού από την αποθήκη βάσει εγκεκριμένου Issue Request (χορήγηση). |
| **Transfer** | Μετακίνηση υλικού από μια θέση σε άλλη μέσα στην αποθήκη. Η συνολική ποσότητα δεν αλλάζει. |
| **Adjustment** | Διόρθωση αποθέματος ώστε να συμφωνεί με την πραγματικότητα. |
| **Stock Count** | Απογραφή: φυσική καταμέτρηση και σύγκριση με το λογιστικό υπόλοιπο. |
| **Reorder Point** | Ελάχιστο επίπεδο αποθέματος κάτω από το οποίο το υλικό πρέπει να αναπληρωθεί. |
| **Replenishment Request** | Αίτημα αναπλήρωσης υλικού που δημιουργείται αυτόματα όταν το συνολικό απόθεμα πέσει κάτω από το Reorder Point. Εγκρίνεται από τον Υπεύθυνο Αποθήκης. Δεν είναι παραγγελία προς προμηθευτή. |
| **Reversal** | Κίνηση που ακυρώνει μια προηγούμενη κίνηση, με αντίθετη ποσότητα. |

## Business Rules

### Απόθεμα
- **BR-01:** Όταν μια κίνηση θα έκανε το απόθεμα μιας θέσης αρνητικό, τότε απορρίπτεται.
- **BR-02:** Όταν δημιουργείται κίνηση, τότε η ποσότητα πρέπει να είναι θετική. Η κατεύθυνση (είσοδος/έξοδος) ορίζεται από τον τύπο της κίνησης.
- **BR-03:** Όταν μια κίνηση εξόδου κάνει το συνολικό απόθεμα ενός υλικού (σε όλες τις θέσεις) να πέσει κάτω από το Reorder Point, τότε δημιουργείται Replenishment Request σε κατάσταση «Προς έγκριση».
- **BR-03a:** Όταν για το υλικό υπάρχει ήδη ανοιχτό Replenishment Request, τότε δεν δημιουργείται νέο.

### Ιστορικό
- **BR-04:** Όταν καταχωρηθεί μια κίνηση, τότε δεν μπορεί να τροποποιηθεί ή να διαγραφεί. Λάθη διορθώνονται μόνο με Reversal.
- **BR-05:** Όταν γίνεται Reversal, τότε πρέπει να αναφέρεται στην αρχική κίνηση, και μια κίνηση δεν μπορεί να αντιστραφεί δεύτερη φορά.

### Παραλαβή
- **BR-06:** Όταν καταχωρείται παραλαβή υλικού με ημερομηνία λήξης, τότε είναι υποχρεωτική η καταχώρηση παρτίδας και ημερομηνίας λήξης.
- **BR-07:** Όταν η ημερομηνία λήξης είναι ήδη παρελθοντική κατά την παραλαβή, τότε η παραλαβή απορρίπτεται.
- **BR-08:** Όταν η παραληφθείσα ποσότητα είναι μικρότερη από την Expected Quantity, τότε η παραλαβή καταχωρείται με την πραγματική ποσότητα, η διαφορά καταγράφεται ως Outstanding Quantity, και ενημερώνονται ο Υπεύθυνος Αποθήκης και η Επιτροπή Παραλαβής.
- **BR-09:** Όταν παραλαμβάνεται συμπλήρωση, τότε η ποσότητά της δεν μπορεί να ξεπερνά την Outstanding Quantity.

### Χορήγηση
- **BR-10:** Όταν δεν υπάρχει εγκεκριμένο Issue Request, τότε η χορήγηση απορρίπτεται.
- **BR-11:** Όταν η χορηγούμενη ποσότητα ξεπερνά την εγκεκριμένη του Issue Request, τότε η χορήγηση απορρίπτεται.
- **BR-12:** Όταν χορηγείται υλικό με ημερομηνία λήξης, τότε προτείνεται πρώτα η παρτίδα που λήγει νωρίτερα (FEFO).
- **BR-13:** Όταν μια παρτίδα έχει λήξει, τότε δεν μπορεί να χορηγηθεί.

### Διορθώσεις & Απογραφή
- **BR-14:** Όταν ένα Adjustment μειώνει την ποσότητα μιας θέσης κατά περισσότερο από 20% της ποσότητας πριν τη διόρθωση, τότε απαιτεί έγκριση από τον Υπεύθυνο Αποθήκης πριν εφαρμοστεί. Τα Adjustments που αυξάνουν την ποσότητα εφαρμόζονται χωρίς έγκριση.
- **BR-15:** Κάθε Adjustment έχει υποχρεωτική αιτιολογία από τη λίστα: Φθορά, Απώλεια, Λάθος καταμέτρησης.
- **BR-15a:** Όταν μια παραλαβή ή χορήγηση καταχωρήθηκε λάθος, τότε διορθώνεται με Reversal της αρχικής κίνησης και νέα σωστή κίνηση, όχι με Adjustment.
- **BR-16:** Όταν μια θέση βρίσκεται σε ενεργή απογραφή, τότε δεν επιτρέπεται καμία κίνηση σε αυτή (παραλαβή, χορήγηση, μεταφορά, διόρθωση) μέχρι να κλείσει η απογραφή. Δεν υπάρχουν εξαιρέσεις.
- **BR-17:** Μόνο ο Υπεύθυνος Αποθήκης μπορεί να κλείσει μια απογραφή. Όταν κλείνει, τότε κάθε διαφορά γίνεται ξεχωριστό Adjustment με τη δική του αιτιολογία. Τα Adjustments αυτά θεωρούνται εγκεκριμένα με το κλείσιμο και δεν περνούν από τον BR-14.

### Θέσεις & Υλικά
- **BR-18:** Όταν μια θέση έχει απόθεμα, τότε δεν μπορεί να απενεργοποιηθεί.
- **BR-19:** Όταν ένα υλικό έχει ιστορικό κινήσεων, τότε δεν διαγράφεται, μόνο απενεργοποιείται.
- **BR-20:** Όταν δημιουργείται νέο υλικό, τότε ο Υπεύθυνος Αποθήκης ορίζει τον κωδικό SKU, ο οποίος είναι μοναδικός και δεν αλλάζει ποτέ. Ο κωδικός είναι υποχρεωτικός, έχει μήκος 3 έως 20 χαρακτήρες, περιέχει μόνο λατινικά γράμματα (A-Z), ψηφία (0-9) και παύλα (-), και δεν ξεκινά ούτε τελειώνει με παύλα. Πριν τον έλεγχο, τα κενά στην αρχή και στο τέλος αφαιρούνται και τα πεζά μετατρέπονται σε κεφαλαία (π.χ. " ab-12 " → "AB-12"). Το SKU περιγράφει το υλικό και όχι τη θέση του.

## Εκτός scope (μελλοντικά)
- Πολλαπλές αποθήκες και μεταφορές μεταξύ τους
- Κοστολόγηση αποθέματος (FIFO / μέση τιμή)
- Παραγγελίες προς προμηθευτές και ειδοποίηση προμηθευτή για συμπλήρωση
